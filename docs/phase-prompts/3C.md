## Passos

1. Trechos curtos: em src/rag/chunking.py, build_chunks ganha o parâmetro min_chars: int = 0 (o padrão 0 mantém o comportamento atual). Com min_chars > 0: uma página cujo texto retido soma menos de min_chars não gera trecho; um trecho final menor que min_chars é anexado ao trecho anterior da mesma página (com "\n"), mesmo que passe de max_chars. Em src/config.py adicione RAG_MIN_CHUNK_CHARS: int = 120 (e no .env.example). O CLI python -m src.rag.index passa min_chars=settings.RAG_MIN_CHUNK_CHARS.
