2. Crie `src/rag/calibration.py` com estas funções (nomes e assinaturas exatos):
   - `load_labeled(path) -> list[dict]`: lê o JSONL e devolve os registros na ordem do arquivo, sem alterá-los. Levanta `ValueError` para categoria fora de `answerable|uncovered|off_topic`, `lang` fora de `pt|en`, `id` repetido, ou `answerable` com `gold_urls` ou `gold_snippets` vazios.
   - `dataset_sha256(records) -> str`: sha256 de `"\n".join(json.dumps(r, ensure_ascii=False, sort_keys=True) for r in records)` em UTF-8.
   - `normalize_text(s) -> str`: `" ".join(s.split()).lower()` (sem regex).
   - `threshold_grid() -> list[float]`: `[round(0.30 + 0.01 * i, 2) for i in range(66)]`.
   - `evaluate(records, query_vectors, chunks, chunk_vectors) -> dict`: para cada consulta, normalize o vetor (L2), calcule o cosseno com `chunk_vectors` convertidos para float64, ordene com `np.argsort(-scores, kind="stable")`. Por consulta: `id`, `lang`, `category`, `top1_score`, `top1_chunk_id`, `top1_url`, `gold_rank` (posição 1..10 do primeiro trecho cujo `doc_url` está em `gold_urls`, senão `None`) e `answer_hit@3` (True se algum dos 3 primeiros trechos tem `doc_url` em `gold_urls` e contém algum `gold_snippet` após `normalize_text` dos dois lados; `None` para categorias que não são `answerable`). Devolve `{"per_query": [...], "retrieval": {...}}`, onde `retrieval` tem, só sobre `answerable`: `n`, `hit@1`, `hit@3`, `hit@5`, `mrr@10` (média de 1/gold_rank, 0 quando None), `answer_hit@3`, e `by_lang` com as mesmas chaves para `pt` e `en`.
   - `abstention_curve(per_query, thresholds) -> list[dict]`: para cada t (responde se `top1_score >= t`): `threshold`, `answer_rate` (fração de answerable respondidas), `off_topic_abstain_rate`, `uncovered_abstain_rate`, `balanced_accuracy` = (answer_rate + off_topic_abstain_rate) / 2, `abstain_precision` (entre answerable+off_topic abstidas, fração off_topic; `None` se nenhuma abstida) e `abstain_recall` (= off_topic_abstain_rate).
   - `choose_threshold(curve) -> float`: maior `balanced_accuracy` (compare com `round(x, 9)`); em empate, a mediana inferior dos limiares empatados em ordem crescente (`cands[(len(cands) - 1) // 2]`).
   - `run_embed(dataset_path, out_npy, out_meta, embedder=None, sleep_s=0.5)`: sem `embedder`, usa `get_embedder("RETRIEVAL_QUERY")`. Chama `embedder.embed_query(query)` para cada consulta, na ordem (nunca `embed_documents`), confere o tamanho `settings.EMBEDDING_DIM` (senão `ValueError`), espera `sleep_s` entre chamadas, salva `np.float32` com shape (n, dim) sem normalizar, e grava o JSON `{"embedding_model", "dim", "task_type": "RETRIEVAL_QUERY", "query_ids", "dataset_sha256", "created_at"}` (UTC ISO).
   - `run_report(dataset_path, emb_npy, emb_meta, index_dir, out_json, out_md) -> dict`: levanta `ValueError` se `query_ids` ou `dataset_sha256` do JSON não batem com o dataset, ou se modelo/dimensão não batem com o índice (use `VectorIndex.load(index_dir, expected_model=meta["embedding_model"], expected_dim=meta["dim"])` e os vetores `index.embeddings`). Calcula `evaluate`, `abstention_curve(threshold_grid())`, `choose_threshold` e os avisos do SPEC (`weak_separation`, `uncovered_not_filtered`, `low_answer_hit`, `threshold_at_grid_edge`, lista ordenada). Grava o JSON com as chaves `generated_at`, `dataset` (`path`, `sha256`, `n_queries`, `by_category`, `by_lang`), `index` (`dir`, `embedding_model`, `dim`, `n_chunks`, `corpus_sha256` do index_meta.json), `query_embeddings` (`path`, `created_at`), `retrieval`, `abstention` (`calibration_set`: "answerable vs off_topic", `rule` em texto, `curve`, `chosen_threshold`, `at_chosen`), `per_query` (linhas de `evaluate` mais `decision_at_chosen`: "answer" ou "abstain") e `warnings`. O Markdown é gerado pelo mesmo código: tabela de métricas (geral e por idioma), limiar escolhido com as taxas em `at_chosen` (inclusive `uncovered`), curva nos limiares múltiplos de 0.05 mais o escolhido, tabela por consulta e avisos. Crie as pastas de saída se faltarem.
   - CLI: `python -m src.rag.calibration embed` e `python -m src.rag.calibration report`, com caminhos padrão `data/eval/retrieval_labeled.jsonl`, `data/eval/retrieval_query_embeddings.npy`, `data/eval/retrieval_query_embeddings.json`, `settings.INDEX_DIR`, `reports/retrieval_calibration.json` e `reports/retrieval_calibration.md`. `embed` sem chave imprime uma mensagem clara e sai com código 2. `report` imprime o limiar escolhido e hit@3.
