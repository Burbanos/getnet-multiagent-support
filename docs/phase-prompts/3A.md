3. Crie src/rag/__init__.py (vazio) e src/rag/ingest.py com:
   - USER_AGENT = "getnet-multiagent-support-ingest/1.0 (+https://github.com/Burbanos/getnet-multiagent-support)"
   - ALLOWED_DOMAINS = {"www.getnet.net", "www.santander.com.br", "www.getnet.com.br"}
   - MIN_CHARS = 300
   - extract_text(html: str) -> tuple[str, str]: devolve (título da tag <title>, texto). Use BeautifulSoup com "html.parser". Remova script, style, noscript, nav, header, footer, form, svg, iframe e aside. Use <main>, senão <article>, senão <body>. Texto com get_text("\n"), linhas com strip(), sem linhas vazias.
   - class Ingestor(client: httpx.Client | None = None, user_agent: str = USER_AGENT, min_delay_s: float = 1.0). Sem client, crie httpx.Client(follow_redirects=True, timeout=15).
     * Toda requisição (inclusive robots.txt) envia o header User-Agent = user_agent.
     * Limite de taxa por host: no mínimo min_delay_s entre requisições ao mesmo host.
     * robots.txt: busque https://<host>/robots.txt uma única vez por host (cache). 200 -> urllib.robotparser com as linhas; 404 ou 410 -> tudo permitido; qualquer outro status ou erro de rede -> tudo bloqueado. Verifique can_fetch(user_agent, url).
     * fetch(url: str, market: str) -> dict com as chaves url, final_url, market, status, http_status, fetched_at (ISO 8601 em UTC, com fuso), title, text, sha256 (do text em UTF-8), chars (len(text)).
       - host fora de ALLOWED_DOMAINS -> status "off_allowlist", SEM nenhuma requisição.
       - robots bloqueia -> "robots_disallowed", sem requisitar a página.
       - erro de rede -> "fetch_error"; HTTP diferente de 200 -> "http_error".
       - redirecionamento para host fora de ALLOWED_DOMAINS -> "off_allowlist".
       - texto extraído com menos de MIN_CHARS -> "no_content".
       - caso contrário "ok". Registros que não são "ok" têm text "", sha256 null e chars 0.
     * run(sources_path="data/sources.yaml", out_dir="data/corpus") -> dict de contagens por status. Grava out_dir/pages.jsonl (um registro por fonte, na ordem do sources.yaml, JSON UTF-8 com ensure_ascii=False) e out_dir/manifest.json com user_agent, generated_at, sources_file_sha256, counts e records (url, status, http_status, fetched_at, sha256, chars).
   - Bloco if __name__ == "__main__" para rodar com python -m src.rag.ingest, imprimindo as contagens.
