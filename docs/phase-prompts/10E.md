3. Construtores de URL (funções puras; precisam reproduzir EXATAMENTE as URLs do `manifest.json` da 10D):
   - `geocoding_url(city: str, country_code: str | None = None) -> str` = `GEOCODING_URL + "?" + urlencode(params, quote_via=quote)` com `params = {"name": city, "count": 1, "language": "pt", "format": "json"}` e, se houver, `"countryCode": country_code` por último (`from urllib.parse import quote, urlencode`).
   - `forecast_request_url(latitude, longitude, forecast_days: int) -> str` = `f"{FORECAST_URL}?latitude={latitude}&longitude={longitude}&current=temperature_2m,weather_code&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max,precipitation_sum&timezone=auto&forecast_days={forecast_days}"`.
   - `moedas_url() -> str` = `OLINDA + "Moedas?$format=json"`.
   - `ptax_period_url(currency: str, start: date, end: date) -> str` = a mesma forma do script da 10D, com as datas em `MM-DD-AAAA` (`d.strftime("%m-%d-%Y")`).

4. Função interna `_get_json(client, url) -> tuple[Any, str | None]`: faz `client.get(url)` e devolve `(json, None)` ou `(None, erro)`, com `erro` = `"timeout"` para `httpx.TimeoutException`, `"network_error"` para outros `httpx.HTTPError`, `f"http_{status}"` para status diferente de 200 e `"invalid_payload"` para corpo que não é JSON. Quando `client` for None, as funções públicas criam `httpx.Client(timeout=settings.PUBLIC_DATA_TIMEOUT_S, headers={"User-Agent": USER_AGENT}, follow_redirects=True)` e fecham ao terminar; quando for passado, usam-no sem fechar.

5. `fetch_weather(city, country_code=None, forecast_days=3, *, client=None) -> dict`:
   - Validação (sem chamada de rede): `city` precisa ser texto com 1 a 100 caracteres depois de `strip()` (senão `error="invalid_city"`); `country_code`, se vier, precisa ter 2 letras ASCII (é convertido para maiúsculas; senão `"invalid_country_code"`); `forecast_days` inteiro de 1 a 7 (senão `"invalid_forecast_days"`). Resultado de validação: `{"status": "invalid_request", "source": WEATHER_SOURCE, "source_url": None, "error": <código>}`.
   - Geocodificação com `geocoding_url(city.strip(), country_code)`. Erro de `_get_json` → `{"status": "unavailable", "source": WEATHER_SOURCE, "source_url": <url>, "error": <erro>}`. Sem `results` ou lista vazia → `{"status": "not_found", "source": WEATHER_SOURCE, "source_url": <url da geocodificação>, "city": <city.strip()>}`. Primeiro resultado sem `latitude`/`longitude` → `unavailable` com `"invalid_payload"`.
   - Previsão com `forecast_request_url(lat, lon, forecast_days)`. Erro → `unavailable` como acima (inclusive o 400 vira `"http_400"`). Resposta sem `daily`, sem `daily_units`, sem `daily["time"]`, sem alguma chave de `DAILY_VARS` em `daily` ou com listas de tamanhos diferentes → `unavailable`, `"invalid_payload"`.
   - Sucesso (chaves exatas):
     `{"status": "success", "source": WEATHER_SOURCE, "source_url": <url da previsão>, "geocoding_url": <url da geocodificação>, "attribution": WEATHER_ATTRIBUTION, "retrieved_at": <ISO 8601 UTC>, "location": {...}, "timezone": <forecast["timezone"] ou None>, "current": {...} ou None, "days": [...]}`.
     - `location`: `name`, `admin1`, `country`, `country_code`, `latitude`, `longitude`, `timezone` do primeiro resultado da geocodificação (None quando faltar).
     - `current` (None se a resposta não tiver `current`): `{"time": current["time"], "temperature": {"value": current["temperature_2m"], "unit": current_units["temperature_2m"]}, "weather_code": <código>, "weather_description": WMO_CODES.get(<código>)}` (use `.get` e None para o que faltar).
     - `days`: para cada índice `i` de `daily["time"]`: `{"date": daily["time"][i], "weather_code": wc, "weather_description": WMO_CODES.get(wc), "temperature_max": {"value": daily["temperature_2m_max"][i], "unit": daily_units["temperature_2m_max"]}, "temperature_min": {...temperature_2m_min...}, "precipitation_probability_max": {...}, "precipitation_sum": {...}}` (unidade via `daily_units.get(...)`, None se faltar).

6. `fetch_exchange_rate(currency, date=None, *, client=None, today=None) -> dict` (`date` é `datetime.date`; `today` padrão `datetime.now(BRT).date()`). Como o parâmetro se chama `date`, NÃO importe `date` de `datetime` no módulo (o ruff reprova a redefinição): use `import datetime as dt` e anote `date: dt.date | None`.
   - Validação: `currency` texto que, depois de `strip().upper()`, tem 3 letras ASCII e não é `BRL` (senão `"invalid_currency"`); `date`, se vier, não pode ser depois de `today` (senão `"future_date"`). Resultado: `{"status": "invalid_request", "source": FX_SOURCE, "source_url": None, "error": <código>}`.
   - Consulta `moedas_url()`. Erro → `{"status": "unavailable", "source": FX_SOURCE, "source_url": <url>, "error": <erro>}`; `value` que não é lista → `unavailable`, `"invalid_payload"`. Moeda fora da lista (`simbolo`) → `{"status": "not_found", "source": FX_SOURCE, "source_url": moedas_url(), "currency": <moeda>}`.
   - Período: com `date`, de `date` a `date`; sem `date`, de `today - timedelta(days=LATEST_LOOKBACK_DAYS)` a `today`. Consulta `ptax_period_url(moeda, inicio, fim)`; erro → `unavailable`; `value` que não é lista → `unavailable`, `"invalid_payload"`.
   - Boletins válidos: itens com `tipoBoletim == CLOSING_BULLETIN` (com `date`, só os de `dataHoraCotacao` começando por `date.isoformat()`). Escolha o de maior `dataHoraCotacao`. Nenhum → `{"status": "no_data", "source": FX_SOURCE, "source_url": <url do período>, "currency": <moeda>, "requested_date": <date.isoformat() ou None>, "period_start": <ISO>, "period_end": <ISO>}`. Boletim escolhido sem `cotacaoCompra`/`cotacaoVenda` numéricos → `unavailable`, `"invalid_payload"`.
   - Sucesso (chaves exatas): `{"status": "success", "source": FX_SOURCE, "source_url": <url do período>, "currency": <moeda>, "currency_name": <nomeFormatado da lista Moedas>, "rate_note": FX_RATE_NOTE, "bulletin": CLOSING_BULLETIN, "quoted_at": <dataHoraCotacao>, "reference_date": <primeiros 10 caracteres de quoted_at>, "requested_date": <date.isoformat() ou None>, "buy": {"value": <cotacaoCompra>, "unit": f"BRL per 1 {moeda}"}, "sell": {"value": <cotacaoVenda>, "unit": f"BRL per 1 {moeda}"}, "retrieved_at": <ISO 8601 UTC>}`.
   - Os valores de cotação saem da resposta como vieram (sem arredondar).
