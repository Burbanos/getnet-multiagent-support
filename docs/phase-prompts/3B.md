## Passos

1. src/config.py: adicione EMBEDDING_MODEL: str = "gemini-embedding-2", EMBEDDING_DIM: int = 768, RAG_TOP_K: int = 4, RAG_MIN_SCORE: float = 0.60 e INDEX_DIR: str = "data/index". Atualize .env.example. Em requirements.txt acrescente numpy>=1.26,<3 (não altere o requirements.lock; ele será regenerado pelo usuário depois da 3C).

2. src/core/llm.py: get_embedder(task_type: str) -> GoogleGenerativeAIEmbeddings(model=settings.EMBEDDING_MODEL, google_api_key=settings.GEMINI_API_KEY, task_type=task_type, output_dimensionality=settings.EMBEDDING_DIM). Sem GEMINI_API_KEY, levanta LLMNotConfiguredError. Leia settings em tempo de execução.

3. src/rag/chunking.py: build_chunks(records: list[dict], max_chars: int = 900, boilerplate_min_pages: int = 4) -> list[dict].
   - Usa apenas registros com status "ok" (formato de data/corpus/pages.jsonl).
   - Linha normalizada = " ".join(linha.split()).lower(). Remove linhas cuja forma normalizada aparece em boilerplate_min_pages ou mais páginas diferentes (rodapé, chamadas de venda repetidas), linhas vazias e linhas sem nenhum caractere alfanumérico (ex.: "—").
   - Agrupa as linhas restantes, na ordem original e SEM alterá-las, em chunks de no máximo max_chars caracteres (linhas unidas por "\n"). Uma linha sozinha maior que max_chars é cortada em max_chars.
   - Cada chunk: chunk_id = f"{doc_sha256[:12]}-{i:03d}" (i sequencial por página), doc_url, title, market, fetched_at, doc_sha256, text.

4. src/rag/index.py:
   - build_index(chunks, embedder, out_dir, embedding_model: str, dim: int, corpus_sha256: str | None = None) -> dict: embedder.embed_documents com os textos dos chunks; vetores normalizados (norma L2 = 1) em float32 gravados em out_dir/embeddings.npy; out_dir/chunks.jsonl (um chunk por linha, UTF-8, ensure_ascii=False); out_dir/index_meta.json com embedding_model, dim, n_chunks, corpus_sha256 e created_at (ISO UTC). Devolve o meta.
   - class VectorIndex com classmethod load(dir, expected_model: str | None = None, expected_dim: int | None = None) que levanta ValueError se embedding_model ou dim do meta não baterem com os esperados; e search(vector, k) -> list[tuple[dict, float]] que normaliza o vetor de consulta e devolve até k pares (chunk, cosseno) em ordem decrescente.
   - CLI python -m src.rag.index: lê data/corpus/pages.jsonl, build_chunks, get_embedder("RETRIEVAL_DOCUMENT"), build_index em settings.INDEX_DIR com embedding_model=settings.EMBEDDING_MODEL, dim=settings.EMBEDDING_DIM e corpus_sha256 = sha256 da concatenação dos campos sha256 dos registros "ok", na ordem do arquivo. Imprime o número de chunks e de páginas.

5. src/rag/retriever.py: class Retriever(index, embedder, min_score: float, top_k: int) com search(query: str) -> dict:
   - Busca top_k com embedder.embed_query(query).
   - Se não houver resultado ou o melhor score for menor que min_score: {"status": "abstain", "query", "documents": [], "min_score"}.
   - Senão: {"status": "success", "query", "documents": [...], "min_score"} com apenas os chunks de score >= min_score; cada documento com url (= doc_url), title, fetched_at, chunk_id, score e text.
