## Passo 2 — Aplicar o texto do README e a declaração das execuções

Salve o script abaixo, **exatamente como está**, num arquivo fora do repositório (por exemplo `$env:TEMP\apply_12f.py`) e
rode-o a partir da raiz do repositório: `python $env:TEMP\apply_12f.py`. Ele lê as seções "Edições do `README.md`" e
"Edições de `reports/run_context.json`" deste arquivo e troca cada "Trecho atual" pelo "Novo trecho", na ordem; se um trecho
não for encontrado exatamente uma vez, ele para sem gravar nada. Depois apague o arquivo do script.

```python
import re
import sys
from pathlib import Path

prompt = Path("docs/phase-prompts/12F.md").read_text(encoding="utf-8").replace("\r\n", "\n")
targets = {"text": Path("README.md"), "json": Path("reports/run_context.json")}
results = {}
for kind, path in targets.items():
    blocks = re.findall(r"^~~~~" + kind + r"\n(.*?)\n~~~~$", prompt, re.S | re.M)
    if not blocks or len(blocks) % 2:
        sys.exit(f"{path}: blocos não encontrados")
    content = path.read_text(encoding="utf-8").replace("\r\n", "\n")
    for i in range(0, len(blocks), 2):
        old, new = blocks[i], blocks[i + 1]
        found = content.count(old)
        if found != 1:
            sys.exit(f"{path}, edição {i // 2 + 1}: trecho atual encontrado {found} vezes; nada foi gravado")
        content = content.replace(old, new, 1)
    results[path] = (content, len(blocks) // 2)
for path, (content, n) in results.items():
    path.write_text(content, encoding="utf-8", newline="\n")
    print(f"{path}: {n} edições aplicadas")
```
