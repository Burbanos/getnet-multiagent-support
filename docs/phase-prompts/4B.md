## Passos

1. Dependência (commit separado): acrescente a linha `langgraph-checkpoint-sqlite>=3.1,<4` ao `requirements.txt`. Faça commit SÓ desse arquivo com a mensagem "chore: declare langgraph-checkpoint-sqlite dependency" e dê push para a main. Instale localmente com `pip install "langgraph-checkpoint-sqlite>=3.1,<4"` (não instale pelo lock no Windows).

2. PARE e peça ao usuário para regenerar o lock no GitHub Codespaces, no terminal, na raiz do repositório, exatamente:
   ```bash
   git pull
   docker run --rm -v "$PWD":/w -w /w python:3.11-slim sh -c "pip install -q pip-tools && pip-compile --output-file=requirements.lock --strip-extras requirements.txt"
   git diff --stat requirements.lock
   git add requirements.lock
   git commit -m "chore: regenerate lock with langgraph-checkpoint-sqlite"
   git push
   ```
   Aguarde ele confirmar. Depois rode `git pull` e confira que `requirements.lock` contém `langgraph-checkpoint-sqlite==`, `aiosqlite==`, `sqlite-vec==` e ainda `langgraph-checkpoint==4.3.1`. Se não contiver, pare e avise.

3. Qualquer erro sobe. Em `src/config.py` adicione `CHECKPOINT_DB_PATH: str = "data/checkpoints.db"`; acrescente `CHECKPOINT_DB_PATH=data/checkpoints.db` ao `.env.example` e `CHECKPOINT_DB_PATH=${CHECKPOINT_DB_PATH:-data/checkpoints.db}` ao `docker-compose.yml`. No `.gitignore`, garanta `*.db-wal` e `*.db-shm` (o SQLite em modo WAL cria esses arquivos).

4. `src/core/graph.py`: `OrchestrationGraph.__init__` ganha o parâmetro `checkpointer=None`; `None` mantém `MemorySaver()` (é o que os testes e os verificadores usam). `get_orchestrator()` passa a criar `OrchestrationGraph(checkpointer=build_sqlite_checkpointer(settings.CHECKPOINT_DB_PATH))`, lendo `settings` na hora.

5. `src/core/auth.py`:
   - `auth_mode()`: com `API_KEYS` preenchido, devolve `"invalid"` se `parse_api_keys` levantar `ValueError`, senão `"configured"`.

   - `authenticate`: se montar a tabela levantar `ValueError`, responda `HTTPException(503, "Authentication misconfigured: check API_KEYS.")` em vez de 500.

6. `src/main.py`: o `lifespan` chama `validate_auth_config()` e `get_orchestrator()` antes do `yield`, para o app NÃO subir com `API_KEYS` inválido ou com `CHECKPOINT_DB_PATH` inutilizável. Em `/` e `/agents`, troque as menções a `MemorySaver` pela descrição real (SqliteSaver em `CHECKPOINT_DB_PATH`, thread `user_id:session_id`).
