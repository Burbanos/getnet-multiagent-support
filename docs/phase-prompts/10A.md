   ```python
   def match_patterns(self, text: str) -> str | None:
       """Return "prompt_injection" when an INJECTION_PATTERNS entry matches the lowercased text,
       "attack_request" when a TOXIC_PATTERNS entry matches, else None. Injection is checked first."""
   ```

3. Novo `src/eval/guardrail_eval.py` (sem `re`, sem imports de `tests/`), com:
   - Constantes `VALID_LABELS = {"block", "allow"}`, `VALID_KINDS = {"prompt_injection", "prompt_leak", "attack_request", "legit"}`, `VALID_SOURCES = {"audit_probe", "safety_case", "paraphrase", "near_miss"}`, `VALID_SPLITS = {"dev", "holdout"}`, `VALID_LANGS = {"pt", "en"}`, `CASE_KEYS = {"id", "lang", "label", "kind", "source", "split", "text"}` e `DEFAULT_SET_PATH = Path("data/eval/guardrail_labeled.jsonl")`.
   - `load_guardrail_set(path) -> list[dict]`: lê o JSONL (UTF-8, linhas vazias ignoradas) e levanta `ValueError` (com o número da linha) para JSON inválido, chaves diferentes de `CASE_KEYS`, valor fora dos conjuntos válidos, `id` repetido, `text` vazio ou só espaços, e rótulo incoerente (`label == "allow"` se e somente se `kind == "legit"`).
   - `guardrail_set_sha256(cases) -> str`: sha256 hex de `"\n".join(json.dumps(c, ensure_ascii=False, sort_keys=True) for c in cases)` em UTF-8 (a mesma forma canônica de `src/eval/cases.py`).
   - `rates(cases, blocked: dict[str, bool]) -> dict` com as chaves `n_block`, `n_allow`, `blocked_block` (casos `block` bloqueados), `blocked_allow` (casos `allow` bloqueados), `block_rate` (= `blocked_block / n_block`, `round(..., 4)`, `None` se `n_block == 0`), `false_positive_rate` (= `blocked_allow / n_allow`, mesmo arredondamento, `None` se `n_allow == 0`), `missed` (ids `block` não bloqueados, ordenados) e `false_positives` (ids `allow` bloqueados, ordenados). Um id ausente de `blocked` conta como não bloqueado.
   - `layer_metrics(cases, blocked) -> dict` com `"all": rates(cases, blocked)`, `"by_split": {split: rates(casos do split, blocked)}` para `"dev"` e `"holdout"`, e `"by_kind": {kind: {"n": ..., "blocked": ...}}` para cada `kind` presente, em ordem alfabética.
   - `pattern_results(cases, agent=None) -> dict[str, str | None]`: para cada caso, `agent.match_patterns(case["text"])` (cria `GuardrailAgent()` se `agent` for None). Não depende de `ENABLE_GUARDRAILS`.
   - `write_pattern_report(cases, out_json, out_md, set_path) -> dict`: grava e devolve o JSON com exatamente as chaves `set_path` (string com barras `/`), `set_sha256`, `n_cases`, `layer` (`"patterns"`), `generated_at` (ISO 8601 UTC), `metrics` (= `layer_metrics(cases, {id: categoria is not None})`) e `cases` (lista na ordem do arquivo, cada item com exatamente `id`, `label`, `kind`, `split`, `blocked` (bool) e `category` (a categoria ou None)); `json.dumps(..., ensure_ascii=False, indent=2)`. O Markdown tem exatamente este formato (taxas com duas casas, ponto decimal; `nenhum` quando a lista estiver vazia; ids separados por `, `):
     ```
     # Guardrail: camada de padrões

     Conjunto: `<set_path>` (sha256 `<set_sha256>`), <n_cases> mensagens. Gerado em <generated_at>.

     | Recorte | Injeções e ataques bloqueados | Legítimas bloqueadas (falsos positivos) |
     |---|---|---|
     | todos | <blocked_block>/<n_block> (<block_rate>) | <blocked_allow>/<n_allow> (<false_positive_rate>) |
     | dev | ... |
     | holdout | ... |

     Não bloqueadas pelos padrões: <missed de "all">
     Falsos positivos: <false_positives de "all">
     ```
