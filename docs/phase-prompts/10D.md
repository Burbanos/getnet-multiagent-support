     `f"https://api.open-meteo.com/v1/forecast?latitude={latitude}&longitude={longitude}&current=temperature_2m,weather_code&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max,precipitation_sum&timezone=auto&forecast_days=3"`.
   - `def capture(client: httpx.Client, out_dir: Path) -> dict`: faz os GETs abaixo, NA ORDEM, e para cada um grava o corpo da resposta sem alteração em `out_dir / f"{name}.json"` (bytes da resposta, como vieram). Depois grava `out_dir / "manifest.json"` (`json.dumps(..., ensure_ascii=False, indent=2, sort_keys=True)`) e devolve o mesmo dict:
     `{"captured_at": <ISO 8601 UTC>, "user_agent": USER_AGENT, "files": {name: {"url": <a URL pedida, como string>, "status_code": <int>, "content_type": <cabeçalho content-type ou None>, "bytes": <tamanho do corpo>, "sha256": <sha256 hex do corpo com "\r\n" trocado por "\n">}}}`.
     Qualquer exceção de rede (`httpx.HTTPError`) interrompe a captura e propaga (o manifesto não é gravado). Respostas com status diferente de 200 são gravadas normalmente (o caso `forecast_invalid` é um 400 de propósito).
     Os GETs (nome → URL):
     - `geocoding_porto_alegre` → `https://geocoding-api.open-meteo.com/v1/search?name=Porto%20Alegre&count=1&language=pt&format=json&countryCode=BR`

     - `forecast_invalid` → `https://api.open-meteo.com/v1/forecast?latitude=999&longitude=0&daily=temperature_2m_max&timezone=auto&forecast_days=3`
     - `ptax_moedas` → `OLINDA + "Moedas?$format=json"`
     - `ptax_eur_20261106` → `ptax_period_url("EUR", "11-06-2026", "11-06-2026")` (sexta-feira, dia útil)
     - `ptax_usd_20261106` → `ptax_period_url("USD", "11-06-2026", "11-06-2026")`
